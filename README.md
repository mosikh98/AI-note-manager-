# دفترچه — نوت‌بردار هوشمند

یک اپ نوت‌برداری تک‌کاربره، کاملاً سمت کلاینت (بدون بک‌اند)، با:

- ذخیره‌ی نوت‌ها در `localStorage` مرورگر
- دکمه‌ی «مرتب‌سازی با هوش مصنوعی»: متن به‌هم‌ریخته را به یادداشت ساخت‌یافته با عنوان و بخش‌بندی تبدیل می‌کند
- پیوست عکس و هر نوع فایل به هر نوت
- خروجی گرفتن از هر نوت به فرمت‌های Markdown، TXT، HTML، PDF و Word (.docx)
- پشتیبانی از سه سرویس هوش مصنوعی: **OpenRouter**، **OpenAI**، **Anthropic** یا هر سرویس سازگار با فرمت OpenAI (سفارشی)

## اجرای محلی

```bash
npm install
npm run dev
```

## بیلد برای انتشار

```bash
npm run build
```

خروجی در پوشه‌ی `dist/` قرار می‌گیرد؛ یک اپ استاتیک است و روی هر هاستی (Netlify، Vercel، GitHub Pages، سرور خودت) قابل سرو کردن است.

## تنظیم کلید API

داخل اپ روی آیکن ⚙️ (تنظیمات) بزن، سرویس را انتخاب کن. برای مدل رایگان کافی است **OpenCode Zen** را انتخاب کنی — baseUrl و مدل (`mimo-v2.5-free`) خودشان پر می‌شوند، فقط کلید API را از [opencode.ai/zen](https://opencode.ai/zen) بگیر و وارد کن.

برای بقیه‌ی سرویس‌ها هم می‌توانی مدل را دستی عوض کنی، مثلاً:

```
google/gemini-2.5-flash                      (OpenRouter)
google/gemini-2.5-flash-lite:free             (OpenRouter، رایگان بسته به موجودی)
mimo-v2.5-free                                 (OpenCode Zen، کاملاً رایگان)
```

کلید فقط در `localStorage` همان مرورگر ذخیره می‌شود و مستقیماً از مرورگر به سرویس انتخابی ارسال می‌شود؛ به هیچ سرور واسطی نمی‌رود.

## اتصال به فضای ابری

هر نوت را می‌توان مستقیماً از داخل اپ در گوگل‌درایو یا دراپ‌باکس ذخیره کرد (داخل یک پوشه به اسم «دفترچه»، شامل فایل Markdown نوت و تمام پیوست‌هایش). چون اپ بک‌اند ندارد، باید یک اپلیکیشن OAuth مخصوص خودت بسازی:

**گوگل‌درایو:**
1. برو به [Google Cloud Console](https://console.cloud.google.com/) → یک پروژه بساز.
2. در APIs & Services → Library، **Google Drive API** را فعال کن.
3. در APIs & Services → Credentials، یک **OAuth Client ID** از نوع **Web application** بساز.
4. آدرس دامنه‌ای که اپ را روی آن سرو می‌کنی (مثلاً `http://localhost:5173` برای توسعه یا آدرس واقعی سایتت) را به **Authorized JavaScript origins** اضافه کن.
5. Client ID ساخته‌شده را در تنظیمات اپ (بخش «اتصال به فضای ابری») وارد کن.

اسکوپ استفاده‌شده `drive.file` است — یعنی اپ فقط به فایل‌هایی که خودش می‌سازد دسترسی دارد، نه کل درایوت.

**دراپ‌باکس:**
1. برو به [Dropbox App Console](https://www.dropbox.com/developers/apps) → Create app → دسترسی «App folder» یا «Full Dropbox» را انتخاب کن.
2. در تنظیمات اپ، همان آدرسی که سایتت را روی آن سرو می‌کنی را به **Redirect URIs** اضافه کن.
3. App Key را در تنظیمات اپ (بخش «اتصال به فضای ابری») وارد کن.
4. اولین بار که روی «دراپ‌باکس» در منوی «آپلود در ابر» بزنی، به صفحه‌ی ورود دراپ‌باکس منتقل می‌شوی و بعد از تأیید، برمی‌گردی.

## بیلد خودکار با GitHub Actions

فایل `.github/workflows/build.yml` با هر پوش به شاخه‌ی `main` اپ را بیلد می‌کند و خروجی را به‌صورت artifact قابل‌دانلود ذخیره می‌کند.

برای دیپلوی خودکار روی GitHub Pages:

1. ریپازیتوری را روی گیت‌هاب بساز و کد را پوش کن.
2. در Settings → Pages، گزینه‌ی Source را روی **GitHub Actions** بگذار.
3. با پوش بعدی به `main`، اپ خودش بیلد و روی Pages منتشر می‌شود (لینک در تب Actions همان اجرا نمایش داده می‌شود).

## ساختار پروژه

```
src/
  App.jsx                  چیدمان کلی و مدیریت state
  components/
    Sidebar.jsx             فهرست نوت‌ها و جست‌وجو
    NoteEditor.jsx           ویرایشگر، نوار ابزار AI/پیوست/خروجی
    AttachmentChip.jsx       نمایش هر پیوست
    SettingsModal.jsx        تنظیمات سرویس هوش مصنوعی
  lib/
    ai.js                    فراخوانی سرویس‌های OpenRouter/OpenAI/Anthropic
    exporters.js             خروجی md/txt/html/pdf/docx
    attachments.js           تبدیل فایل به base64
    storage.js                ذخیره‌سازی در localStorage
```

## نکته‌ها

- حجم localStorage معمولاً حدود ۵ مگابایت است؛ برای پیوست‌های حجیم (ویدیو، فایل‌های بزرگ) بهتر است بعداً یک بک‌اند/فضای ابری اضافه شود.
- اگر سرویس انتخابی CORS را برای فراخوانی مستقیم از مرورگر نبندد (OpenRouter و OpenAI این‌طور هستند)، دکمه‌ی مرتب‌سازی بدون نیاز به سرور واسط کار می‌کند.
